# 夜勤脱出(night-shift-escape)

夜勤中の病院を探索し、制限時間内に3つのアイテムを集めてナースステーションへ戻る、Godot製の2D探索ゲームです。

> **現在の状況:** 開発初期(初期セットアップのみ完了。ゲーム本体は未実装)

## ゲーム概要

| 項目 | 内容 |
|---|---|
| ジャンル | 2D探索ゲーム |
| 舞台 | 夜勤中の病院(小規模マップ1つ) |
| 制限時間 | 約3分 |
| 集めるアイテム | 鍵・カルテ・懐中電灯 |

※アイテムはゲーム用の架空のものです。実際の医療行為・薬剤・患者情報は扱いません。

## ゲームの目的

制限時間内に病院を探索して3つのアイテムをすべて集め、ナースステーションへ戻るとクリアです。時間切れになるとゲームオーバーになります。

```
ゲーム開始 → 病院を探索 → 3つのアイテムを集める → ナースステーションへ戻る → クリア
```

## MVP(最初に完成させる範囲)

- **プレイヤー:** 上下左右に移動できる。壁は通り抜けられない。
- **マップ:** 小規模な病院マップ1つ(ナースステーション・廊下・数個の部屋)。
- **アイテム:** 鍵・カルテ・懐中電灯。
- **UI:** 残り時間、アイテム取得数、クリア画面、ゲームオーバー画面、リスタート。

敵・戦闘・複数ステージ・セーブ機能などは、MVPの対象外です。詳しい仕様は[PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md)を参照してください。

## AIの役割分担

このプロジェクトでは、複数のAIを役割分担して使っています。**最終判断はAIではなく開発者本人が行います。**

| AI | 役割 |
|---|---|
| ChatGPT | 要件整理、ゲーム設計、技術選択、実装方針、学習・コード理解のサポート |
| Claude Code | Godotプロジェクトの実装、コード作成・変更、テスト、デバッグ、リファクタリング |
| Gemini | 設計レビュー、コードレビュー、品質・パフォーマンス確認、別の実装案の提示 |

AIが生成したコードについても、主要な部分は開発者自身が説明できる状態を目指しています。

## 開発目的

小さなゲームを「企画 → 完成 → 公開」まで1本作り切り、その一連の流れに慣れることが目的です。技術的な高度さより、決めた範囲(MVP)を期間内に完成させることを優先しています。
